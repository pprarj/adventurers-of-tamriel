# Adventurers of Tamriel

An adventurers' guild for Skyrim: a guild board of ranked contracts, from F to
S, and promotion earned through points and proof.

**Status: early development.** Nothing here is released yet.

## License

No license has been chosen yet. One will be added before the first outside
contribution is accepted.

## What is in this repository, and what is not

```
Scripts/Source/     Papyrus source (.psc)
plugin-skse/        SKSE plugin source (C++), when the project has one
```

**This repository holds the source of what players receive.** The development
records - design notes, phase logs, decision history - and the development
tools live in a separate private repository, on purpose.
